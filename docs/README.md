# Trung Tâm Tài Liệu KotoBase

Tài liệu dự án được tổ chức theo từng chủ đề để dễ theo dõi trong quá trình phát triển và vận hành.

## Danh sách tài liệu

- [SETUP.md](./SETUP.md): Hướng dẫn cài đặt, cấu hình biến môi trường, chạy local và xử lý lỗi thường gặp.
- [ARCHITECTURE.md](./ARCHITECTURE.md): Tổng quan kiến trúc hệ thống, cấu trúc thư mục, luồng dữ liệu và mô hình dữ liệu.

## Gợi ý đọc nhanh

1. Bắt đầu với [SETUP.md](./SETUP.md) để chạy dự án trên máy local.
2. Tiếp theo đọc [ARCHITECTURE.md](./ARCHITECTURE.md) để hiểu cách tổ chức và mở rộng hệ thống.
